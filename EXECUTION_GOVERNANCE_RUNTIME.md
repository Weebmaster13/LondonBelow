# Execution Governance Runtime

`ExecutionGovernanceRuntime` is the schema wrapper for `ExecutionGovernance` records.

Fields:

- `governanceId`
- `decisionId`
- `executionReadinessId`
- `governanceKind`
- `governanceStatus`
- `runtimeName`
- `providerName`
- `snapshotProviderName`
- `requirementIds`
- `assessmentIds`
- `findingIds`
- `auditIds`
- `evidence`
- `tags`
- `metadata`

Governance records describe copied eligibility metadata only.
