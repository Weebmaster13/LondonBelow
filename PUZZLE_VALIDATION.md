# Puzzle Validation

`PuzzleValidation` rejects missing ids, duplicate ids, malformed graphs, invalid nodes, invalid edges, invalid dependencies, invalid conditions, unsupported puzzle types, unsafe metadata/context, client fields, remote fields, Workspace fields, Roblox Instances, functions, userdata, threads, oversized payloads, deep payloads, animation, audio, lighting, UI, inventory, gameplay execution, interaction execution, door execution, drawer execution, Monster AI, Narrative, Save, Horror pacing, Chapter content, story, dialogue, and cutscene fields.

It also rejects duplicate nodes, duplicate edges, duplicate dependencies, duplicate conditions, unsafe tags, and graph/node/dependency/condition count limit violations.
