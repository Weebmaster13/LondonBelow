# Interaction Validation

`InteractionValidation` protects the runtime from unsafe or premature gameplay.

Validation rejects missing ids, duplicate ids, unsupported types, missing physical object ids, unsafe eligibility, unsafe metadata/context, invalid cooldowns, invalid locks, client fields, remotes, Workspace references, Roblox Instances, functions, threads, userdata, cycles, oversized strings, oversized payloads, deep payloads, animation, audio, UI, lighting, physics, movement, inventory execution, door execution, drawer execution, pickup execution, puzzle completion, Monster AI, Narrative, Save, Horror pacing, Chapter content, story, dialogue, and cutscene fields.
