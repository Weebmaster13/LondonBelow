# Governance

Governance system name: Roblox Visual Composition Runtime Foundation.

Owner layer: Presentation.

Status: ProductionCandidate.

Provider and snapshot provider: `robloxVisualCompositionRuntime`.

The contract owns visual composition metadata only and explicitly does not own
GUI instantiation, Roblox Instance mutation, visual rendering, client
rendering, camera execution, animation execution, audio execution, asset
loading, localization resolution, accessibility execution, networking,
persistence, gameplay, dialogue, AI, analytics, telemetry, or client authority.
