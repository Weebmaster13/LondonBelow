# Evidence Metrics Profiler

Evidence records definition registration and rejection, composition creation,
binding, compile start, revision commit, stale revision rejection, compilation,
activation, supersession, release, runtime reset, runtime shutdown, and runtime
failures.

Metrics track registered definitions, rejected definitions, created
compositions, resolved compositions, activations, supersessions, releases,
compilation failures, validation failures, stale revisions, ownership conflicts,
compiled nodes, layers, regions, accessibility nodes, localization slots, and
asset references.

Profiler records bounded internal metadata for validation, compilation,
revision commit, diagnostics capture, and snapshot capture. No telemetry is
exported.
