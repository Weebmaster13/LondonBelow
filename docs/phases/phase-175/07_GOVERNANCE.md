# Governance

The Governance contract is `Dialogue Presentation Contract Foundation`.

Dialogue owns the contract metadata. A future Presentation Runtime owns realization and consumption.

Phase 175 does not own UI rendering, text rendering, subtitle rendering, camera control, animation playback, voice playback, audio routing, localization resolution, input capture, networking, remotes, persistence, Workspace mutation, gameplay execution, client authority, analytics, or telemetry.
