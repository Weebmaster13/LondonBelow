# Governance

Governance registers `Runtime Domain Capability Foundation` as a Core Production Candidate contract.

The contract owns domain capability metadata and integration boundaries only. It does not own concrete domain implementation, gameplay rules, dialogue trees, inventory logic, save serialization, AI behavior, command execution, event publication, query execution, networking, persistence, Workspace mutation, analytics, telemetry, rendering, or client authority.

Snapshot provider: `runtimeDomainCapabilityFoundation`.

Diagnostics provider: `runtimeDomainCapabilityFoundation`.
