# Diagnostics And Snapshots

Diagnostics use provider `runtimeDomainCapabilityFoundation` and posture key `domainCapabilityPosture`.

Diagnostics expose:

- domain capability records;
- interface ownership;
- communication contracts;
- lifecycle integration;
- evidence;
- metrics;
- profiler metadata;
- budgets;
- Governance posture;
- certification posture;
- explicit no-execution and no-authority flags.

Snapshots use provider `runtimeDomainCapabilityFoundation` and key `runtimeDomainCapabilityFoundationSnapshot`. Snapshot output is an isolated copy.
