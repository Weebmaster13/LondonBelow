# Evidence Trust Model

Trust levels:

- `STATIC_ONLY`
- `BUILD_ONLY`
- `INSTALLATION_DISCOVERY`
- `MANUAL_UNVERIFIED`
- `MANUAL_SOURCE_BOUND`
- `AUTOMATED_STUDIO_HOST`
- `AUTHORITATIVE_SERVER_CLIENT`
- `CERTIFICATION_REVIEW_ELIGIBLE`

Phase 152 manual evidence can reach `MANUAL_SOURCE_BOUND` only when it is bound to repository commit, session ID, manifest, Studio version where present, place artifact identity, expected runner schema, and imported result file.

Screenshots and copied console text are not structured evidence. Certification review eligibility is not certification.
