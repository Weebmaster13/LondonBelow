# Phase 155 Runtime Result Schema

The bridge prepares the existing importer-compatible runner result fields. It does not create a second evidence schema.

Required fields: schemaVersion, runnerId, sessionId, phase, repositoryCommit, runtime, status, studioVersion, serverStarted, clientStarted, clientCount, assertions, diagnostics, snapshots, audit, errors, warnings, cleanup, productionCertified, capturedAt.
