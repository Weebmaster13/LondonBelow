# Phase 187 - Governance

Governance declares the hardening boundary, default-deny authority, diagnostics, cleanup, integrity guarantees, and evidence-gated certification posture.

## Ownership

Phase 187 owns its Governance declaration and snapshot contract.

## Non-Ownership

It owns no networking, persistence, gameplay, analytics, telemetry, or server authority.

## Certification Boundary

Governance metadata cannot self-certify the runtime.
