# Phase 185 - Schema and Catalog

Contracts contain exact root identity, source patch identity, target revision, root node, ordered nodes, and metadata. Nodes contain exact identity, class, parent, properties, references, tags, accessibility, and responsive metadata. Unknown fields fail closed.

The initial allowlist covers foundational 2D GUI containers, text, images, buttons, scrolling, viewport presentation, layouts, padding, corner, stroke, gradient, scale, aspect, size, and text-size constraints. Script and remote classes are explicitly forbidden.

## Ownership

This phase owns schema version `1.0.0`, legal class metadata, typed property metadata, limits, and reference kinds.

## Non-Ownership

The catalog does not instantiate classes or guarantee an asset exists.

## Certification Boundary

Catalog completeness is reviewed and self-checked; Studio support remains unverified runtime evidence.
