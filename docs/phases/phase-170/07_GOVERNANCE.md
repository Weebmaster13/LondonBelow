# Governance

Phase 170 adds the `Runtime Capability Framework` Governance contract.

The contract owns capability registration, discovery, lifecycle, versioning, dependency validation, health metadata, diagnostics, inspection, evidence, budgets, compatibility posture, and certification posture metadata.

The contract explicitly does not own gameplay execution, rendering, networking, physics, Workspace mutation, persistence writes, command execution, event publication, query execution, analytics, telemetry, or client authority.

The snapshot provider is `runtimeCapabilityFramework`.
