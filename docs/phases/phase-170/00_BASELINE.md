# Phase 170 Baseline

Phase 170 establishes the Runtime Capability Framework under Core.

Messaging defines communication. Workflow defines orchestration. Capabilities define reusable runtime services and their versioned interfaces.

The framework is infrastructure only. It does not create Dialogue, Objectives, Inventory, Save, AI, Presentation, UI, Navigation, Combat, Weather, Chapter content, gameplay behavior, networking, persistence writes, command execution, event publication, query execution, client authority, or Workspace mutation.

Latest Production Certified remains Phase 108. Phase 170 is a Production Candidate until authoritative Roblox Studio runtime evidence is imported through the Runtime Execution Framework.
