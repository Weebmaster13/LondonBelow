# Diagnostics And Snapshots

Diagnostics expose:

- `capabilityFrameworkPosture`;
- `capabilityRegistry`;
- `capabilityLifecycle`;
- `capabilityDependencyGraph`;
- `capabilityDiscovery`;
- `capabilityHealth`;
- `capabilityEvidence`;
- `capabilityMetrics`;
- `capabilityProfiler`;
- `capabilityBudgets`;
- `capabilityGovernance`;
- `certification`.

Snapshots expose `runtimeCapabilityFrameworkSnapshot`.

All diagnostics and snapshots are deep copied before publication.
