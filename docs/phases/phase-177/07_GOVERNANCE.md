# Governance

The Governance contract is `Presentation Runtime Execution and Session Management`.

The runtime owns execution state only. It explicitly does not own ScreenGui creation, Roblox GUI, TextLabels, ImageLabels, viewport rendering, animation playback, sound playback, camera movement, localization resolution, accessibility rendering, networking, remotes, Workspace mutation, persistence, gameplay, dialogue execution, AI, analytics, telemetry, or client authority.
