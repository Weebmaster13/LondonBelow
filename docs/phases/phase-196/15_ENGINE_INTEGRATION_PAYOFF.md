# Engine Integration Payoff

## Ownership

Phase 196 is the payoff layer for the systems built in Phases 184–195. Blackwater Descent does not merely coexist with them: its live chapter interface executes through them.

| Earlier capability | Blackwater Descent use |
| --- | --- |
| Phase 184 visual composition/diff runtime | Every accepted world beat first creates, seals, prepares, applies, and commits a revision-fenced abstract visual patch plan. |
| Phase 185 GUI instance contracts | The complete HUD is described as a bounded `1.0.0` GUI contract. |
| Phases 186–187 rendering and reconciliation | Objective transitions stage detached trees, atomically commit them, reject stale revisions, and verify integrity. |
| Phases 188–189 interaction/accessibility | Headings, status, narrative, threat, inventory, and progress carry accessible live regions; the Case File uses the generation-fenced input-agnostic action runtime. |
| Phases 190–191 responsive localization | The title resolves from the `en-us` catalog while safe-area and adaptive-text policies classify each viewport. |
| Phases 192–193 animation | Each objective revision enters with a bounded, supersession-safe, reduced-motion-aware CanvasGroup transition. |
| Phases 194–195 theming | Blackwater registers and transactionally applies an immutable visual-token theme, then verifies active values. |
| Observation Engine and Horror Director | Accepted server interactions become trusted facts; objective phases drive Opening, Exploration, Puzzle, Threat, Climax, and Escape pressure. |
| Diagnostics and snapshots | Rendering, interaction, localization, animation, theme, chapter state, counters, audit, and failure records remain inspectable. |

The chapter now exposes objective number, total, narrative discovery, party relic inventory, chapter phase, threat label, pressure, and completion state as read-only replicated attributes. The client coalesces related attribute changes into one revision and never calls the server.

The world also reacts more strongly to progress. Pressure drives the owned color-grade effect; taking the Glass Heart extinguishes every runtime-owned street gaslight; escaping opens the iron gate, advances dawn, extends the fog horizon, and clears pressure. Shutdown destroys the effects and restores the Lighting snapshot.

## Non-Ownership

The integration layer does not give GUI, animation, localization, or theming code gameplay authority. It does not claim Studio execution, final art, final audio, persistence, or a complete monster encounter. It does not bypass the Horror Director to choose threats.

## Certification Boundary

This expansion remains part of the Phase 196 Production Candidate. Its contract rendering, themes, animation, localization, responsive behavior, accessibility metadata, environment reactions, cleanup, solo flow, and multiplayer flow must all be exercised by the exact authoritative Studio matrix before certification.
