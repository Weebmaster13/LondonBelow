# Studio Playthrough Matrix
## Ownership
Importer requires exactly 80 passing cases, phase 196, authoritative true, non-empty Studio run ID, and at least 12 measured playthrough minutes.
## Non-Ownership
Static checks, fabricated evidence, and code size cannot prove game quality.
## Certification Boundary
Missing, partial, extra, malformed, too-short, or failing evidence keeps `executionBlocked`.
