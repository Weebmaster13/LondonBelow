# Player Presentation
## Ownership
The chapter HUD is a real London Engine `1.0.0` GUI contract, not a parallel hand-built interface. It presents chapter title, objective, objective number, Director-derived threat label, narrative discovery, relic inventory, progress, and bounded pressure from replicated server attributes only.

Every coalesced state update increments the presentation revision. Transactional staging and reconciliation own instance creation. The title resolves from the `en-us` localization catalog; safe-area and adaptive-text policies cover compact through expanded viewports. Accessibility metadata identifies headings, narrative, threat alerts, inventory status, objective status, and progress with polite or assertive live regions. Immutable theme tokens own the Blackwater palette. A bounded reduced-motion-aware CanvasGroup transition introduces each revision, followed by render, theme, and animation integrity verification.
## Non-Ownership
HUD never sends gameplay requests, owns chapter truth, derives a threat decision, or uses animation/theme state as gameplay authority.
## Certification Boundary
Desktop, mobile, controller, safe-area, scaling, and readability tests remain required.
