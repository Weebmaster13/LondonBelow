# Phase 196 Diagnostics

## Ownership

Diagnostics expose runtime version, schema version, state, busy flag, active composition identity, bounded counters, bounded failures, rendering diagnostics, and authority posture.

## Non-Ownership

Diagnostics are not analytics, telemetry, save data, or runtime certification evidence.

## Certification Boundary

Diagnostics support inspection only. They cannot certify runtime behavior without authoritative Studio evidence.
