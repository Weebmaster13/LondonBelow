# Self Checks

Phase 173 self-check coverage includes:

- execution start;
- execution context creation;
- deterministic node traversal;
- variable mutation;
- condition evaluation;
- waiting choice state;
- duplicate execution rejection;
- choice selection;
- closed completion state;
- recovery;
- suspension and resumption;
- lowerCamelCase diagnostics;
- snapshot isolation;
- shutdown execution refusal;
- banned runtime surface absence.

The Node wrapper records static self-check evidence and blocked-runtime status without claiming Roblox Studio runtime execution.
