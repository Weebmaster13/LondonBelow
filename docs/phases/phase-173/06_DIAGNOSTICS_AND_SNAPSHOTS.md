# Diagnostics And Snapshots

Diagnostics use provider `dialogueRuntimeExecution` and posture key `dialogueExecutionPosture`.

Diagnostics expose executing conversations, scheduler state, execution queue, runtime variable counts, node transitions, active conditions, pending choices, lifecycle state, evidence, metrics, profiler metadata, budgets, Governance, certification posture, and explicit no-execution/no-authority flags.

Snapshots use key `dialogueRuntimeExecutionSnapshot` and return isolated copies.
