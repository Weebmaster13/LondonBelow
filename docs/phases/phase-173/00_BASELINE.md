# Phase 173 Baseline

Phase 173 transforms Dialogue from a structural runtime capability into a deterministic runtime execution service.

Dialogue Execution owns conversation execution, runtime state machine metadata, node traversal, choice processing, condition evaluation, runtime variables, participant synchronization metadata, diagnostics, snapshots, evidence, metrics, and profiler metadata.

Dialogue Execution does not own gameplay, UI, rendering, NPC behavior, AI decisions, inventory, objectives, save serialization, networking, persistence, Workspace mutation, command execution, event publication, query execution, remotes, analytics, telemetry, or client authority.

Latest Production Certified remains Phase 108. Phase 173 is a Production Candidate until authoritative Roblox Studio runtime evidence is imported through the Runtime Execution Framework.
