# Governance

Governance registers `Dialogue Runtime Execution and State Management` as a Dialogue-owned Production Candidate contract.

The contract owns deterministic conversation execution state only. It does not own rendering, UI, NPC behavior, AI decisions, inventory, objectives, save serialization, networking, persistence, Workspace mutation, command execution, event publication, query execution, or client authority.

Snapshot provider: `dialogueRuntimeExecution`.

Diagnostics provider: `dialogueRuntimeExecution`.
