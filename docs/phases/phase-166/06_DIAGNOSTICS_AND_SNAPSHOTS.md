# Diagnostics and Snapshots

Diagnostics expose query posture, registry counts, queue depth, dispatch and execution counts, authorization failures, cache behavior, projection and read-model counts, query metrics, health, profiler data, resource budgets, performance budgets, last query id, and last failure.

Snapshots expose query registry, requester registry, handler registry, lifecycle, queue, routing, execution, projections, read models, cache metadata, consistent read snapshots, diagnostics, and evidence.
