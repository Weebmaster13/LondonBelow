# Diagnostics And Snapshots

Diagnostics provider: `dialogueRuntimeInteraction`

Snapshot provider: `dialogueRuntimeInteraction`

Posture key: `dialogueInteractionPosture`

Diagnostics expose health-only state, bounded records, non-ownership booleans, certification posture, metrics, profiler records, budgets, governance metadata, and internal runtime queue evidence.

Snapshots are isolated deep copies. Mutating a returned snapshot does not mutate runtime state.
