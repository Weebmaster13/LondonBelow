# Self Checks

Phase 174 self-checks cover:

- request creation
- duplicate rejection
- pending queue registration
- invalid response rejection without mutation
- valid response completion
- cancellation
- timeout closure
- interruption and resume metadata
- nested conversation metadata
- lowerCamelCase provider and posture keys
- diagnostics non-ownership flags
- snapshot isolation
- runtime validation
- shutdown blocking
- cleanup after reset

Static automation wrapper: `npm run london:phase174:selfcheck`.
