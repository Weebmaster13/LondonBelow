# Chapter 0 Objectives

Chapter 0 Home objectives:

- `chapter0.objective.inspectMumsNote`: completed when the Mum's Note inspection fact is recorded.
- `chapter0.objective.restorePower`: completed when the kitchen breaker reaches `ON`.
- `chapter0.objective.openFrontDoor`: completed when the front door reaches `OPEN`.
- `chapter0.objective.leaveHome`: active after the door objective completes and completed by the `chapter0.home.leaveHomeReached` runtime event.

These objectives are intentionally minimal and do not fabricate broader chapter completeness.
