# Diagnostics

Diagnostics provider:

- `gameplayFlowRuntime`

Key diagnostics:

- `gameplayFlowRuntimePosture`
- `activeObjective`
- `completedObjectives`
- `failedObjectives`
- `queuedEvaluations`
- `conditionEvaluations`
- `objectiveTransitions`
- `checkpointEligible`

Diagnostics are health and state visibility only. They do not certify production runtime execution.
