# Snapshots

Snapshot provider:

- `gameplayFlowRuntime`

Snapshot fields:

- `gameplayFlowRuntimeAvailable`
- `gameplayFlowRuntimePosture`
- `activeObjective`
- `objectiveCounts`
- `checkpointEligible`
- `evaluationCount`
- `transitionCount`
- `evidenceCount`

Snapshots are isolated deep copies and are bounded in memory.
