# Features And Configuration

Feature declarations are capability metadata, not execution permission.

Supported features include dialogue windows, choice menus, notifications, HUD, menus, overlays, portrait rendering, subtitle rendering, caption rendering, camera planning, animation planning, and audio planning.

Renderer configuration records maximum sessions, descriptors, queue depth, acknowledgements, synchronization records, snapshot size, feature flags, and runtime priority. Configuration is copied at registration time and remains immutable through diagnostics and snapshots.
