# Diagnostics And Snapshots

Diagnostics expose provider identity, capability identity, platform, renderer registry, capability registry, compatibility matrix, evidence, metrics, profiler metadata, limits, Governance, certification posture, counters, failures, and lowerCamelCase `robloxRenderingPosture`.

Snapshots use provider `robloxRenderingRuntime` and expose `robloxRenderingSnapshot`. Snapshot payloads are deep copies and cannot mutate runtime state.
