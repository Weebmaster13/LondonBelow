# Governance

Phase 181 adds a Governance contract for Roblox Rendering Capability Foundation.

Governance records server authority, provider `robloxRenderingRuntime`, capability `robloxRenderingCapability`, platform `Roblox`, Bootstrap dependency on `PresentationRenderingExecutionCoordinator`, diagnostics provider, snapshot provider, and explicit non-ownership boundaries.

Governance is passive metadata and does not certify runtime execution.
