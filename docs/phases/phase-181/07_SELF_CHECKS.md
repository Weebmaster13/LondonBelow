# Self Checks

Phase 181 self-checks cover:

- runtime identity
- renderer registration
- duplicate renderer rejection
- unsupported platform rejection
- unsupported rendering kind rejection
- capability registration
- duplicate capability rejection
- unsupported feature rejection
- compatibility negotiation
- unsupported contract and descriptor rejection
- unknown renderer rejection
- diagnostics isolation
- snapshot isolation
- evidence, metrics, profiler, limits, Governance, and certification posture
- reset and shutdown behavior
- prohibited runtime surface absence through automation wrapper checks

Automation entry points:

- `npm run london:phase181:selfcheck`
- `npm run london:roblox-rendering`
- `npm run london:roblox-rendering:validate`
