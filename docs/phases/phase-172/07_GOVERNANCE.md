# Governance

Governance registers `Dialogue Runtime Capability Foundation` as a Dialogue-owned Production Candidate contract.

The contract owns conversation metadata only. It does not own rendering, UI widgets, animations, voice playback, subtitles, player input, NPC AI, inventory, objectives, networking, persistence, Workspace mutation, command execution, event publication, query execution, or client authority.

Snapshot provider: `dialogueRuntimeCapability`.

Diagnostics provider: `dialogueRuntimeCapability`.
