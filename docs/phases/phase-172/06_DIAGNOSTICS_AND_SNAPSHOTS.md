# Diagnostics And Snapshots

Diagnostics use provider `dialogueRuntimeCapability` and posture key `dialogueCapabilityPosture`.

Diagnostics expose registered dialogues, active conversations, participant registry, state machine metadata, condition evaluation counts, node transition counts, evidence, metrics, profiler metadata, budgets, Governance, certification posture, and explicit no-execution/no-authority flags.

Snapshots use key `dialogueRuntimeCapabilitySnapshot` and return isolated copies.
