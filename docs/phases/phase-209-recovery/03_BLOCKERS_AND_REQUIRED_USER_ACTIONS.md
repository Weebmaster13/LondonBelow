# Blockers And Required User Actions

Blocking condition:

* Roblox audio IDs are empty.
* Assets are candidate-only.
* No playback occurs.
* Permissions are unknown.
* Studio listening was not executed.
* Mix quality is untested.

Required user action:

1. Select and approve specific source audio files for each Phase 209 scene.
2. Confirm the license is acceptable for Roblox game use and derivative editing.
3. Authorize downloading and derivative editing.
4. Authorize Roblox audio upload or provide the uploaded Roblox audio asset IDs.
5. Confirm the experience has permission to use the uploaded IDs.
6. Run or authorize a Roblox Studio listening pass after IDs are bound.

Completion tier remains Implementation Incomplete until these blockers are resolved.
