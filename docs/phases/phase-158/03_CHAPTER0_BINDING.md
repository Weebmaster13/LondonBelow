# Chapter 0 Binding

`Chapter0EnvironmentalCoordinator` binds Chapter 0 Home fixtures into the existing Environmental Interaction Runtime.

It owns only Chapter 0 fixture metadata and binding readiness. It does not own global interaction validation, remotes, Workspace mutation, asset spawning, save persistence, analytics, telemetry, Monster AI, combat, inventory, or Chapter 1 content.

Provider:
- `chapter0EnvironmentalRuntime`

Diagnostics posture:
- `chapter0EnvironmentalBindingPosture`
