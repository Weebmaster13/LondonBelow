# Acoustic Propagation

Phase 206 defines acoustic profiles for the street, entrance, foyer, drawing room, gallery, service corridor, kitchen, cellar, crypt, ward chambers, archive, ritual chamber, reliquary, blackout house, and dawn street.

Each profile describes reverb character, wet balance, decay, high-frequency absorption, low-frequency reinforcement, and active emitter budget.

The runtime publishes active acoustic zone state and keeps propagation bounded. No unbounded raycast loop is introduced.
