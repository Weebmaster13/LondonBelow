# Surface Foley

`BlackwaterAudioExecutionConfig` defines eleven surfaces:

- Wet cobblestone.
- Dry stone.
- Mud.
- Gravel.
- Wood floor.
- Damaged wood.
- Carpet.
- Tile.
- Metal stair.
- Shallow puddle.
- Dust/debris.

Movement states include slow walk, walk, sprint, crouch, stop, turn, jump, land, stumble, stair ascent, stair descent, and injured movement.

The runtime creates deterministic non-repeating variation plans. It does not play Sound instances until approved assets exist.
