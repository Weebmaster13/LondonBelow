# Phase 221 Asset Requirements

Required before production quality can be claimed:

* Final or near-final Golden Route environment models, materials, props, lighting, and optimization.
* Bailiff concept approval, model, rig, textures, materials, and at least twenty working animations.
* Licensed audio files, edited derivatives, checksums, Roblox asset IDs, permission state, runtime playback, and Studio listening evidence.
* Final puzzle, cinematic, secret, shortcut, and accessibility route evidence.

Configuration entries do not count as final assets.
