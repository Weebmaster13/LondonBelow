# Phase 198 - The Bailiff Monster Production and Hunting Intelligence

## Baseline

Phase 198 adds The Bailiff as Blackwater Descent's signature monster authority, layered under the existing Chapter 196 production coordinator.

## Ownership

Owned by `BlackwaterMonsterRuntime`, with identity and fairness values in `BlackwaterProductionConfig`.

## Non-Ownership

The Bailiff runtime does not own horror pacing, final animation, final audio, final rigging, networking, remotes, persistence, or client truth. It remains subordinate to Chapter pressure, Observation flow, and Director intent.

## Implementation

The Bailiff has an explicit identity, origin, relationship to Blackwater House, Glass Heart escalation, silhouette language, audio signature, and an eighteen-state lifecycle: Unspawned, Dormant, Foreshadow, Patrol, Stalk, Observe, Investigate, Suspicious, Hunt, Search, Ambush, DoorPressure, Recover, Retreat, Climax, Disabled, and Shutdown.

Transitions are guarded by an allowed-state table. Invalid transitions are rejected and recorded as fairness incidents. The runtime reacts to objective progress and pressure: lantern lighting creates foreshadowing, the buried ward triggers investigation, archive opening raises suspicion, Glass Heart removal enters climax, and escape disables the monster. Target selection is deterministic and weights noise while applying target cooldowns.

## Validation

`london:phase198:selfcheck` verifies Bailiff identity, state catalog, transition rejection, target fairness fields, coordinator integration, HUD publication, and forbidden surfaces.

## Certification Boundary

Production Candidate only. The current Bailiff presentation uses a runtime proxy silhouette. Final rig, animation, pathfinding Studio evidence, and fair-play verification remain blocked.

## Known Limitations

Physical locomotion remains represented by deterministic state and authored proxy behavior. Studio pathfinding and animation evidence are required before the monster can be considered production-certified.

Phase 199 builds survival mechanics around the Bailiff's perception and chase authority.
