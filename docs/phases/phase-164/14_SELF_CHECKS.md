# Self-Checks

Phase 164 self-check automation validates source coverage for registries, immutable envelopes, payload validation, publisher authorization, priority and FIFO ordering, queue overflow posture, deterministic routing, delivery isolation, normalized results, cancellation, duplicate event ID protection, replay metadata, recursive publish protection, diagnostics, snapshots, evidence, shutdown, Bootstrap, Governance, package scripts, and forbidden surface absence.

Luau module self-checks are provided in `EventSelfChecks.lua` for authoritative runtime execution when Studio evidence is available.
