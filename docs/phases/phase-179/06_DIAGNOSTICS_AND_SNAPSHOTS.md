# Diagnostics And Snapshots

`RenderingRuntimeDiagnostics` exposes provider identity, runtime identity, renderer registry, sessions, assignments, acknowledgements, synchronization, evidence, metrics, profiler metadata, budgets, governance, certification, counters, failures, and `renderingRuntimePosture`.

`RenderingRuntimeSnapshots` publishes immutable deep-copy snapshots through `presentationRenderingRuntime`.
