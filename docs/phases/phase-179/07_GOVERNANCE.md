# Governance

Governance registers `Presentation Rendering Runtime Capability Foundation`.

The contract documents Presentation ownership, server authority, deterministic renderer assignment, session isolation, renderer isolation, diagnostics, snapshots, evidence, cleanup behavior, failure modes, and prohibited responsibilities.

The runtime explicitly prohibits GUI creation, rendering, asset loading, networking, persistence, Workspace mutation, gameplay execution, dialogue execution, AI execution, analytics, telemetry, and client authority.
