# Diagnostics And Snapshots

`RenderingDiagnostics` exposes provider identity, contract identity, contracts, renderer capabilities, rendering requests, acknowledgements, synchronization records, references, evidence, metrics, profiler records, budgets, governance, certification, counters, failures, and `renderingContractPosture`.

`RenderingSnapshots` publishes `presentationRuntimeRenderingContractSnapshot` through provider `presentationRuntimeRenderingContract`.

Diagnostics and snapshots are immutable deep copies.
