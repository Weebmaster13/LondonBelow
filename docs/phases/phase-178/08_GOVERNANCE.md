# Governance

Governance registers `Presentation Rendering Contract Foundation`.

The contract documents Presentation ownership, server authority, data-only descriptors, immutable rendering requests, immutable acknowledgements, deterministic compatibility, deterministic synchronization, diagnostics, snapshots, evidence, cleanup behavior, failure modes, and prohibited responsibilities.

The contract explicitly prohibits GUI creation, rendering, asset loading, localization resolution, accessibility implementation, networking, persistence, Workspace mutation, gameplay execution, dialogue execution, analytics, telemetry, and client authority.
