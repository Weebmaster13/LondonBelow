# Phase 208 Perception Evidence

The Bailiff now records typed perception evidence:

* direct sight
* partial sight
* movement at distance
* player sound
* moving interactive object
* door movement
* lantern activation
* ward disturbance
* teammate noise
* scripted narrative trigger
* occupied hiding location
* last-known position
* suspicious environmental change

Each evidence item has position, strength, confidence, expiration, priority, source category, and optional player identity. Evidence ranking drives source-side production state.
