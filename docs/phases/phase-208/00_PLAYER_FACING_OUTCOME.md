# Phase 208 Player-Facing Outcome

Phase 208 makes the Bailiff read as a corrupted civic authority rather than a generic threat. During source-driven play, interactions now create typed evidence for the Bailiff, the runtime ranks that evidence, exposes a readable production state, prevents duplicate encounter execution, and gives the HUD a concise state/evidence read.

The player-facing improvement is clearer cause and effect: lantern activation, ward disturbance, and noisy interaction can move the Bailiff into listening, investigating, suspicious, or pursuit-adjacent states without claiming magic omniscience.
