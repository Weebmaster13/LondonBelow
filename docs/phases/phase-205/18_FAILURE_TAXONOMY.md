# Failure Taxonomy

Phase 205 failure states:

- `notStarted`
- `implementationInProgress`
- `implementedUnverified`
- `staticVerified`
- `studioBlocked`
- `studioFailed`
- `studioPassed`
- `humanPlaytestRequired`
- `humanPlaytestFailed`
- `humanPlaytestPassed`
- `assetReplacementRequired`
- `productionCandidate`
- `productionCertified`

Certification must never advance from these labels by inference.
