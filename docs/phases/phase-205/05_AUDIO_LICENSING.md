# Audio Licensing

Phase 205 does not approve final audio.

Every candidate requires:

- Source page verification.
- Uploader verification.
- License verification for Roblox use.
- Download checksum.
- Edit log.
- Human approval.
- Roblox upload.
- Experience permission check.
- Studio audition.

Until all steps are complete, each candidate remains `replacementRequired` and `assetUploadBlocked`.
