# Accessibility

Phase 205 adds street audio captions and visual equivalents so audio-only pressure events have a non-audio surface.

Required Studio accessibility checks:

- Keyboard input.
- Gamepad input.
- Touch input.
- Reduced-motion posture.
- Captions for major authored audio events.
- Visual equivalents for non-diegetic pressure cues.
- Objective and ending text readability.

Current evidence state: static coverage only.
