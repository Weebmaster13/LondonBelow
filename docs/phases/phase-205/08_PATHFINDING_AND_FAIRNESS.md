# Pathfinding And Fairness

The physical Bailiff runtime exposes path planning but does not bypass the existing Bailiff state authority.

Fairness requirements for Studio validation:

- The Bailiff must have a visible physical source.
- Chase pressure must remain readable.
- Recovery reposition must be explicit and rare.
- Blocked paths must fail with classified results.
- The proxy must never create hidden client-owned threat truth.
