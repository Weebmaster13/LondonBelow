# Governance

Phase 182 adds a Governance contract for Roblox Rendering Session Runtime.

Governance records server authority, provider `robloxRenderingSessionRuntime`, capability `robloxRenderingSessionRuntimeCapability`, platform `Roblox`, Bootstrap dependency on `RobloxRenderingCoordinator`, diagnostics provider, snapshot provider, and explicit non-ownership boundaries.

Governance remains passive metadata and does not certify runtime execution.
