# Self Checks

Phase 182 self-checks cover:

- runtime identity
- session creation
- duplicate session rejection
- execution-session mapping
- duplicate mapping rejection
- reservation correctness
- reservation conflict rejection
- ownership correctness
- lifecycle transitions
- scheduling determinism
- diagnostics isolation
- snapshot isolation
- evidence, metrics, profiler, budgets, Governance, and certification posture
- reset and shutdown behavior
- prohibited runtime surface absence through automation wrapper checks

Automation entry points:

- `npm run london:phase182:selfcheck`
- `npm run london:roblox-rendering-session`
- `npm run london:roblox-rendering-session:validate`
