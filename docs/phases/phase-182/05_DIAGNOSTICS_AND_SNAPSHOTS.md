# Diagnostics And Snapshots

Diagnostics expose provider identity, capability identity, platform, session registry, execution mappings, ownership, reservations, scheduling, evidence, metrics, profiler metadata, budgets, Governance, certification posture, counters, failures, and lowerCamelCase `robloxRenderingSessionPosture`.

Snapshots use provider `robloxRenderingSessionRuntime` and expose `robloxRenderingSessionSnapshot`. Snapshot payloads are deep copies and cannot mutate runtime state.
