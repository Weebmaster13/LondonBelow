# Self Checks

Phase 176 self-checks cover:

- capability registration
- consumer registration
- duplicate consumer rejection
- session creation
- duplicate session rejection
- unknown consumer rejection
- deterministic queue ordering
- illegal lifecycle rejection
- assignment and lifecycle progression
- acknowledgement production
- duplicate acknowledgement rejection
- synchronization satisfaction
- diagnostics posture
- evidence, metrics, and profiler records
- governance and certification posture
- snapshot isolation
- reset behavior
- shutdown behavior
- prohibited responsibility posture

Static automation wrapper: `npm run london:phase176:selfcheck`.
