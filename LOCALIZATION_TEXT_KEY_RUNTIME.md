# Localization Text Key Runtime

Text keys are identifiers, not final written dialogue.

Text key schemas require `textKeyId`, `ownerSystem`, optional `schemaType = LocalizationTextKeySchema`, safe metadata, safe context, and safe tags.

Text keys may name future content slots, but they must not contain final story prose, final dialogue, Chapter content, rendered subtitles, or translated text.

Future content writers may target text keys later, but the keys themselves remain identifiers and constraints, not authored content.
