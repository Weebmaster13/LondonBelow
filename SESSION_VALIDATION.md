# Session Validation

Session validation rejects malformed session schemas, duplicate session ids, duplicate player session ids, malformed party schemas, duplicate party ids, malformed readiness records, malformed lifecycle records, malformed join/leave records, unsafe metadata/context/tags, Roblox Instances, unsafe runtime values, cycles, oversized payloads, and deep payloads.

It also rejects client/remote fields, Workspace fields, teleport and matchmaking execution fields, save persistence fields, lobby UI fields, party gameplay fields, Monster AI, Narrative, Horror, Chapter, story, dialogue, cutscene, UI, Audio, Lighting, and Camera fields.
