# Asset Execution Implementation Readiness Diagnostics

Diagnostics are health-only. They expose lifecycle state, counts, limit usage, validation failure count, snapshot count, implementation readiness posture, no-loading posture, no-execution posture, recent sanitized validation failures, and the last self-check result.

Diagnostics do not expose services, asset handles, loaded assets, runtime handles, remotes, Workspace references, execution adapters, or client authority.
