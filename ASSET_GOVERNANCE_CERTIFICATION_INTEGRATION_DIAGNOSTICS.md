# Asset Governance Certification Integration Diagnostics

Diagnostics are health-only copied metadata.

Diagnostics expose lifecycle state, counts, limit usage, runtime limits, provider posture, certification integration coordination posture, copied certification/dependency/readiness/provider/Bootstrap/documentation/compatibility posture, certified governance chain metadata, documentation metadata, bounded validation failures, and the last self-check result.

Provider and posture keys:

- provider sampler: `assetGovernanceCertificationIntegrationRuntime`
- provider posture: `assetGovernanceCertificationIntegrationRuntime`
- `certificationIntegrationCoordinationPosture`
- `copiedCertificationMetadataPosture`
- `copiedDependencyMetadataPosture`
- `copiedReadinessMetadataPosture`
- `copiedProviderMetadataPosture`
- `copiedBootstrapMetadataPosture`
- `copiedDocumentationMetadataPosture`
- `copiedCompatibilityMetadataPosture`
- `certifiedGovernanceChain`

Diagnostics never expose services, Instances, functions, threads, userdata, runtime handles, callbacks, listeners, execution adapters, client state, remotes, live subsystem references, or mutable internal tables.
