# Runtime Gate Runtime

`RuntimeGate` is the top-level final gate evidence schema.

Fields:

- `gateId`
- `assetId`
- `usagePlanId`
- `checklistId`
- `approvalId`
- `permitId`
- `gateKind`
- `gateStatus`
- `evaluator`
- `checkIds`
- `blockIds`
- `auditIds`
- `tags`
- `metadata`

Runtime gates do not execute assets or grant client authority by themselves.
