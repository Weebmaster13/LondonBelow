# Implementation Contract Responsibility Runtime

`ImplementationContractResponsibility` describes one implementation responsibility attached to an implementation contract.

Fields:

- `responsibilityId`
- `contractId`
- `responsibilityKind`
- `required`
- `summary`
- `tags`
- `metadata`
- `schemaType`

Responsibility records are metadata obligations only. They do not execute loading, spawning, playback, UI, VFX, persistence, networking, gameplay, presentation, save, or Chapter behavior.
