# Execution Governance Assessment Runtime

`ExecutionGovernanceAssessmentRuntime` is the schema wrapper for `ExecutionGovernanceAssessment` records.

Fields:

- `assessmentId`
- `governanceId`
- `requirementId`
- `assessmentKind`
- `assessmentStatus`
- `runtimeName`
- `providerName`
- `snapshotProviderName`
- `evidence`
- `tags`
- `metadata`

Assessments record copied review outcomes only.
