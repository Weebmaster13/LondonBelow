# Readiness Finding Runtime

`ReadinessFinding` records a readiness issue or note attached to a checklist.

Fields:

- `findingId`
- `checklistId`
- `findingKind`
- `severity`
- `summary`
- `resolved`
- `tags`
- `metadata`

Findings are review metadata only. They do not mutate manifests, usage plans, assets, or execution state.
