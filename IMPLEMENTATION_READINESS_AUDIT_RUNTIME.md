# Implementation Readiness Audit Runtime

`ImplementationReadinessAudit` records audit metadata attached to an implementation readiness record.

Fields:

- `auditId`
- `readinessId`
- `auditKind`
- `reviewer`
- `status`
- `findings`
- `tags`
- `metadata`

Audits are schema records only. They do not execute remediation or approve runtime behavior.
