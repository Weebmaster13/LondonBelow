# Execution Governance Finding Runtime

`ExecutionGovernanceFindingRuntime` is the schema wrapper for `ExecutionGovernanceFinding` records.

Fields:

- `findingId`
- `governanceId`
- `assessmentId`
- `findingKind`
- `findingSeverity`
- `findingStatus`
- `summary`
- `evidence`
- `tags`
- `metadata`

Findings are metadata-only review facts and do not block live runtime work.
