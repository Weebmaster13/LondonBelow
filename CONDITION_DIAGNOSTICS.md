# Condition Diagnostics

Condition diagnostics expose lifecycle state, health, validation status, counts for every schema category, runtime limits, limit usage, serialization posture, snapshot isolation proof, diagnostic isolation proof, integrity posture, no-execution posture, recent sanitized validation failures, and last self-check result.

Diagnostics are health data only. They are not live condition truth, evaluation output, analytics, telemetry, profiling, admin tools, remotes, or UI.

All diagnostics are deep copied before returning.

## Production Hardening

Diagnostics explicitly expose no-execution posture for condition, expression, boolean, logic, branching, scripting, rule, trigger, gameplay, puzzle, interaction, inventory, objective, Director, Monster AI, Narrative, Presentation, Save, Scheduler, Lifecycle, Event Graph, Runtime Graph, Rule Engine, orchestration, state mutation, Workspace, remotes, client authority, DataStore, HTTP, messaging, analytics, telemetry, Chapter content, final story, final dialogue, and cutscenes.
