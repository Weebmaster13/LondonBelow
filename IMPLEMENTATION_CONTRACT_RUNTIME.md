# Implementation Contract Runtime

`ImplementationContract` is the top-level future Asset Execution Implementation Contract schema.

Fields:

- `contractId`
- `readinessId`
- `proposedRuntimeName`
- `designContractId`
- `assetId`
- `usagePlanId`
- `checklistId`
- `approvalId`
- `permitId`
- `gateId`
- `contractKind`
- `contractStatus`
- `owner`
- `responsibilityIds`
- `boundaryIds`
- `auditIds`
- `tags`
- `metadata`
- `schemaType`

Implementation contract records describe implementation obligations only. They do not execute assets or grant client authority by themselves.
