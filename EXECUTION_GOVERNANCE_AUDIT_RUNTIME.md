# Execution Governance Audit Runtime

`ExecutionGovernanceAuditRuntime` is the schema wrapper for `ExecutionGovernanceAudit` records.

Fields:

- `auditId`
- `governanceId`
- `assessmentIds`
- `findingIds`
- `auditKind`
- `auditStatus`
- `reviewer`
- `evidence`
- `tags`
- `metadata`

Audits summarize copied governance metadata only.
