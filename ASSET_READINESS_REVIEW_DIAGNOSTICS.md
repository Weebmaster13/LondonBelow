# Asset Readiness Review Diagnostics

Diagnostics are health-only. They expose lifecycle state, counts, limit usage, validation failure count, snapshot count, readiness posture, no-loading posture, no-execution posture, recent sanitized validation failures, and the last self-check result.

Diagnostics do not expose asset handles, runtime handles, services, remotes, player-owned truth, Workspace references, or execution adapters.
