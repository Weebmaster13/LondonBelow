# Implementation Contract Boundary Runtime

`ImplementationContractBoundary` describes one implementation boundary attached to an implementation contract.

Fields:

- `boundaryId`
- `contractId`
- `boundaryKind`
- `allowed`
- `summary`
- `tags`
- `metadata`
- `schemaType`

Boundary records document what future implementation work may or may not own. They do not enforce runtime execution or create asset behavior by themselves.
