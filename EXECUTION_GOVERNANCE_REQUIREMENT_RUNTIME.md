# Execution Governance Requirement Runtime

`ExecutionGovernanceRequirementRuntime` is the schema wrapper for `ExecutionGovernanceRequirement` records.

Fields:

- `requirementId`
- `governanceId`
- `requirementKind`
- `requirementStatus`
- `runtimeName`
- `providerName`
- `snapshotProviderName`
- `required`
- `evidence`
- `tags`
- `metadata`

Requirements describe copied governance obligations only.
