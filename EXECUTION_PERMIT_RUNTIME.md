# Execution Permit Runtime

`ExecutionPermit` is the top-level future permit evidence schema.

Fields:

- `permitId`
- `assetId`
- `usagePlanId`
- `checklistId`
- `approvalId`
- `permitKind`
- `permitStatus`
- `issuedBy`
- `scopeIds`
- `restrictionIds`
- `auditIds`
- `tags`
- `metadata`

Execution permits do not execute assets or grant client authority by themselves.
