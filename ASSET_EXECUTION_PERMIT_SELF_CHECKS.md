# Asset Execution Permit Self-Checks

Self-checks are deterministic and prove valid registration, duplicate rejection, invalid id rejection, unsupported kind/status/severity rejection, missing permit reference rejection, unsafe payload rejection, oversized payload rejection, failed-validation no-mutation, bounded validation failures, bounded snapshots, snapshot isolation, diagnostics isolation, shutdown cleanup, global namespace reset, and banned runtime surface absence.

Self-checks do not perform asset operations and are not gameplay tests.
