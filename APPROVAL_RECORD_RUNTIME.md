# Approval Record Runtime

`ApprovalRecord` is the top-level formal approval evidence schema.

Fields:

- `approvalId`
- `assetId`
- `usagePlanId`
- `checklistId`
- `approvalKind`
- `approvalStatus`
- `approver`
- `conditionIds`
- `revocationIds`
- `auditIds`
- `tags`
- `metadata`

Approval records do not grant execution permission by themselves.
