# Implementation Readiness Runtime

`ImplementationReadiness` is the top-level proposed future Asset Execution Implementation Readiness schema.

Fields:

- `readinessId`
- `proposedRuntimeName`
- `contractId`
- `reviewId`
- `assetId`
- `usagePlanId`
- `checklistId`
- `approvalId`
- `permitId`
- `gateId`
- `readinessKind`
- `readinessStatus`
- `reviewer`
- `checklistIds`
- `gapIds`
- `auditIds`
- `tags`
- `metadata`
- `schemaType`

Implementation readiness records do not execute assets or grant client authority by themselves.
