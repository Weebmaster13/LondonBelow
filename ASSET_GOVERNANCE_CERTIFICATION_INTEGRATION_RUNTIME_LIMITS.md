# Asset Governance Certification Integration Runtime Limits

Runtime limits are declared in `AssetGovernanceCertificationIntegrationTypes.lua`.

- `MaxIntegrations = 40`
- `MaxChains = 120`
- `MaxReviews = 530`
- `MaxAudits = 300`
- `MaxValidationFailures = 240`
- `MaxSnapshotHistory = 60`
- `MaxPayloadDepth = 8`
- `MaxPayloadNodes = 450`
- `MaxStringLength = 280`
- `MaxTags = 32`
- `MaxAuditFindings = 40`
- `MaxReviewEvidence = 40`
- `MaxIntegrationChildren = 180`
- `MaxChainEntries = 120`

Limits bound metadata only. They do not create scheduling, orchestration, persistence, live inspection, repair, execution authorization, or asset execution behavior.
