# Presentation Validation

`PresentationValidation` prevents presentation intent schemas from becoming execution.

Validation rejects missing ids, duplicate presentation ids, unsupported presentation types, missing approvals, duplicate approval ids, missing channels, invalid channels, expired requests, client authority fields, remotes, Workspace references, Roblox Instances, functions, threads, userdata, cycles, oversized strings, oversized payloads, deep payloads, final UI fields, audio execution fields, lighting execution fields, camera execution fields, cutscenes, animation execution, particle/VFX execution, gameplay execution, Monster AI fields, Narrative ownership, Save ownership, Horror pacing, Chapter content, story, and dialogue.
