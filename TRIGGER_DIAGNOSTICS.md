# TRIGGER DIAGNOSTICS

Trigger diagnostics are health-only. They expose lifecycle state, counts, limit usage, validation status, serialization posture, isolation proof, integrity posture, no-execution posture, recent sanitized failures, and last self-check result. They are not trigger evaluation.

## Production Hardening

Production hardening: diagnostics expose initialized, started, lifecycle state, health, validation status, all category counts, limit usage, runtime limits, serialization posture, isolation proof, integrity posture, no-execution posture, recent sanitized failures, and last self-check result. Diagnostics are not trigger monitoring.
