# Lifecycle Guard Runtime

Guards are requirements, not live checks.

Guard records describe dependency, configuration, governance, safety, compatibility, Runtime Graph, security, save, presentation, or future guard requirements. They do not execute checks or call other systems.

## Hardening Rules

Guards reject unsupported guard kinds, live check payloads, Runtime Graph call payloads, Security call payloads, Save call payloads, Presentation call payloads, service resolution payloads, module references, callbacks, and execution adapters. A guard is a requirement record only, never a live check.
