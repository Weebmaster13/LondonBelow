# Execution Permit Restriction Runtime

`ExecutionPermitRestriction` records restriction metadata attached to a permit.

Fields:

- `restrictionId`
- `permitId`
- `restrictionKind`
- `severity`
- `summary`
- `active`
- `tags`
- `metadata`

Restrictions are ledger records only. They do not unload, disable, mutate, or remove assets.
