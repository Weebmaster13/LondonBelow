# Asset Governance Certification Integration Audit

`GovernanceCertificationIntegrationAudit` records copied audit metadata for certification integration coordination.

Audit records include:

- `auditId`
- `integrationId`
- `auditKind`
- `reviewer`
- `status`
- `findings`
- `tags`
- `metadata`

Audit records are not live inspections, repair orders, execution grants, scheduler tasks, orchestration requests, persistence requests, gameplay events, Presentation events, Save events, or Chapter content.
