# World Self-Checks

World self-checks are deterministic and destructive, so they run before startup only.

They prove valid schemas register, malformed and duplicate schemas reject, invalid connection endpoints reject, invalid streaming policies reject, unsafe metadata/context/tags reject, forbidden execution fields reject, serialization rejects unsafe values, snapshots are isolated, diagnostics are read-only, histories are bounded, shutdown clears state, and the runtime contains no Workspace mutation, terrain generation, streaming execution, room loading, teleporting, movement, pathfinding, physics, remotes, client authority, or Chapter content.
