# Tool Command Runtime

Command schemas are inert records.

They describe what a future command could look like, including safe metadata and ownership, but this runtime never executes the command.

Forbidden fields include command execution, admin power, remote console, exploit, backdoor, moderation, analytics collection, DataStore, Workspace, remote, client, teleport, gameplay execution, save mutation, Chapter, story, dialogue, and cutscene fields.

Future command execution requires a separate governed runtime and security review.
